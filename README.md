# FinPlan Pro

A visual, interactive financial planner built for the **FinCal Innovation Hackathon 2026 – Technex, IIT BHU**.

Most financial tools and spreadsheets are overly complicated. **FinPlan Pro** helps people understand how much they need to save for their life goals without needing a finance degree. It translates complex compounding mathematics into intuitive charts and interactive visualizations.

## Why we built this

Many people delay investing because they cannot see the immediate impact of their decisions.

This project was designed to clearly demonstrate the **Cost of Waiting**. By adjusting time and investment parameters, users can visually see how delaying investments significantly increases the amount they must contribute later.

The goal of this project is **financial education**, helping users understand investing concepts through interaction rather than complicated spreadsheets.

---

## Key Features

### Visual Goal Planning
Users can add multiple financial goals such as:

- Higher education  
- Buying a house  
- Retirement planning  
- Travel or lifestyle goals  

The calculator automatically estimates the **future cost of the goal using inflation assumptions**.

---

### Cost of Delay Engine
An interactive slider shows how delaying investments impacts long-term wealth.  
Users can visually see how **missing early years of compounding increases the required monthly investment**.

---

### Compound Growth Visualization
Interactive charts illustrate:

- investment contributions
- compound returns
- total wealth accumulation over time

This helps users understand how **compounding accelerates wealth growth in the long run**.

---

### Inflation Adjusted Planning
The calculator adjusts goal costs based on inflation assumptions to show **realistic future financial requirements**.

---

### Multi-Goal Financial Planning
Unlike traditional calculators that focus on a single objective, this tool allows users to plan **multiple financial goals simultaneously**.

---

### Financial Readiness Insights
A readiness indicator helps users understand whether their current savings strategy is sufficient to achieve their goals.

---

### Downloadable Financial Plan
Users can generate and download a **summary report of their financial plan**, making it easier to review or share their strategy.

## Running the Project Locally

1. Clone the repository

```
git clone https://github.com/your-username/your-repo-name.git
```

2. Navigate to the project folder

```
cd your-repo-name
```

3. Install dependencies

```
npm install
```

4. Start the development server

```
npm run dev
```

5. Open your browser and go to

```
http://localhost:3000
```

## Project Objective

The primary objective of this project is **financial literacy and investor awareness**.

The calculator helps users understand:

- the power of compound interest
- the impact of inflation on financial goals
- the importance of starting investments early
- how time affects long-term wealth creation

Rather than promoting specific financial products, the focus is on **education, visualization, and decision support**.
