A visual, interactive financial planner built for the 2026 Hackathon.

Most financial tools and spreadsheets are overly complicated. We built FinPlan Pro to help people figure out how much they need to save for their life goals without needing a finance degree. It translates complex compounding math into easy-to-read charts.

### Why we built this
People usually put off investing because it's hard to see the immediate impact. We wanted to build a tool that clearly shows the "Cost of Waiting"—visually proving exactly how much extra you'll have to pay out of pocket if you delay investing by a few years.

### What it does
- **Visual Goal Tracking:** Add life goals (like buying a house, travel, or education) and the app calculates the inflation-adjusted future cost.
- **Cost of Delay Engine:** A slider that shows how much money you lose to missed compound interest if you wait to start investing.
- **Coast FIRE Simulation:** See what happens if you invest aggressively for a decade and then just let the money sit.
- **Realistic Returns:** Toggle between pre-tax and post-tax numbers to get a realistic view of your actual take-home wealth.
- **PDF Export:** Generate and download a clean summary report of your financial plan.

### Tech Stack
- **Frontend:** Next.js, React
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **Icons:** Lucide React
